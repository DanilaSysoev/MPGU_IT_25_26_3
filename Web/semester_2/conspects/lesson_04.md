# Урок 4. Шаблонизатор Django (DTL). Принцип DRY

**Тип занятия:** Лекция + Воркшоп  
**Продолжительность:** 3 астрономических часа  
**Сложность:** Средняя (требует абстрактного мышления)  

## Цели урока

1. Понять принцип **DRY** (Don't Repeat Yourself) в контексте верстки.
2. Освоить **наследование шаблонов**: создание базового "скелета" сайта (`base.html`).
3. Научиться передавать данные (контекст) из Python-view в HTML-шаблон.
4. Разобраться с тегами шаблонизатора (`{% if %}`, `{% for %}`) и переменными (`{{ var }}`).
5. Настроить работу со статикой (CSS, картинки) и именованными URL.

## Часть 1. Конспект лекции

### 1. Проблема "Копипасты"

Представьте, что у вас на сайте 50 страниц. На каждой есть "Шапка" (меню) и "Подвал" (контакты). Вдруг у вас изменился номер телефона.

* **Плохой путь:** Открыть 50 файлов `html` и поменять номер вручную.
* **Путь Django:** Использовать **наследование**. Мы выносим общие части в один файл, а уникальные — оставляем в других.

### 2. Синтаксис DTL (Django Template Language)

HTML — это статика. DTL превращает его в динамику.

* `{{ variable }}` — **Переменная**. "Напечатай здесь то, что пришло из View".
  * Пример: `<h1>Привет, {{ username }}!</h1>`
* `{% tag %}` — **Тег (Логика)**. Управляющая конструкция.
  * Пример: `{% if user.is_authenticated %} ... {% endif %}`
* `{{ variable|filter }}` — **Фильтр**. Изменение данных перед показом.
  * Пример: `{{ text|truncatewords:30 }}` (обрезать текст после 30 слов).

### 3. Наследование шаблонов (`extends` и `block`)

> **Аналогия: Картина и Рама.**
> `base.html` — это рама. Она одна для всех картин. В ней есть крепления, стекло, паспарту.
> `index.html`, `about.html` — это холсты. Мы вставляем холст в раму.

**Как это выглядит в коде:**

1. В `base.html` мы размечаем "дырки" (блоки), куда потомки будут вставлять свой контент:

    ```html
    <!-- base.html -->
    <nav>...</nav>
    <main>
        {% block content %}
        <!-- Сюда встанет уникальный контент страницы -->
        {% endblock %}
    </main>
    <footer>...</footer>
    ```

2. В `index.html` мы говорим "Я использую раму base.html":

    ```html
    <!-- index.html -->
    {% extends 'base.html' %}

    {% block content %}
        <h1>Главная страница</h1>
        <p>Ура, я внутри базового шаблона!</p>
    {% endblock %}
    ```

### 4. Статические файлы (`static`)

Django не отдает CSS и картинки просто так, как обычный HTML файл. Ему нужно знать, где они лежат.

1. В `settings.py` есть настройка `STATIC_URL = 'static/'`.
2. В шаблоне нужно загрузить библиотеку: `{% load static %}`.
3. Путь к файлу: `<img src="{% static 'img/logo.png' %}">`.

### 5. Именованные URL (Reversing)

Никогда не пишите ссылки так: `<a href="/about/">`. Если вы решите переименовать страницу в `/info/`, вам придется искать все ссылки по всему проекту.
Пишите так: `<a href="{% url 'about_page' %}">`.
Django сам подставит нужный адрес, опираясь на `urls.py`.

## Часть 2. Практика (Live Coding)

*Преподаватель показывает:*

1. Создание файла `base.html` в папке templates.
2. Перенос туда всего "обвеса" из `index.html` (head, navbar, footer).
3. Использование тега `{% block content %}`.
4. Очистка `index.html` и наследование от `base.html`.
5. Создание второй страницы "О нас" (`about.html`), чтобы показать, как легко теперь создавать новые страницы.

## Часть 3. Домашнее задание №4

**Тема:** Создание многостраничной структуры сайта.  
**Срок выполнения:** 1 неделя.  
**Максимальный балл:** 8 баллов.  

### Описание задания

Вам необходимо рефакторить (улучшить) код вашего проекта, внедрив наследование шаблонов. Ваш сайт должен состоять минимум из двух страниц (Главная и Дополнительная), имеющих общий дизайн (меню и подвал).

### Пошаговая инструкция (ТЗ)

1. **Создание базового шаблона:**
    * Создайте файл `base.html` в папке `templates/ваше_приложение/`.
    * Перенесите в него всю структуру HTML (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`), подключение Bootstrap и навигационное меню (Navbar).
    * Внутри тега `<body>` (там, где должен быть основной контент) вставьте конструкцию:

        ```html
        {% block content %}
        {% endblock %}
        ```

    * Добавьте блок для заголовка вкладки браузера в `<head>`: `<title>{% block title %}Мой сайт{% endblock %}</title>`.

2. **Наследование Главной страницы:**
    * Очистите файл `index.html`.
    * Первой строкой напишите `{% extends 'ваше_приложение/base.html' %}`.
    * Оберните уникальный контент главной страницы в `{% block content %} ... {% endblock %}`.

3. **Создание Второй страницы:**
    * Придумайте вторую страницу (например, "Контакты" или "О нас").
    * Создайте файл `about.html` (или другой по смыслу).
    * Унаследуйте его от `base.html`.
    * Напишите внутри какой-то текст, отличающийся от главной.
    * **Backend:**
        * Напишите функцию-view для этой страницы в `views.py`.
        * Добавьте маршрут (`path`) в `urls.py`. Не забудьте указать `name='about'` (имя придумайте сами).

4. **Навигация (Меню):**
    * В файле `base.html` найдите ссылки в меню (теги `<a>`).
    * Замените атрибуты `href="..."` на динамические теги Django: `href="{% url 'имя_вашего_url_из_urls_py' %}"`.
    * Теперь кнопки меню должны переключать страницы без ошибок.

5. **Контекст (Context Data):**
    * В `views.py` в функцию главной страницы добавьте словарь `context`. Например:
        `context = {'title': 'Главная страница', 'welcome_text': 'Добро пожаловать на наш лучший сайт!'}`.
    * Передайте этот словарь в `render`: `return render(request, '...', context)`.
    * В шаблоне `index.html` выведите эти переменные через `{{ title }}` и `{{ welcome_text }}`.

### Критерии оценивания (Аддитивная система)

Максимум: **8 баллов**.

| Критерий | Баллы | Описание |
| :--- | :---: | :--- |
| **Базовый шаблон (`base.html`)** | **+2** | Файл создан, содержит структуру HTML и блоки `{% block %}`. В нем нет дублирования кода с `index.html`. |
| **Наследование (`extends`)** | **+2** | `index.html` и вторая страница корректно наследуются от базы. Дизайн не "развалился". |
| **Вторая страница** | **+1** | Создана новая страница, View и URL для неё. Она открывается в браузере. |
| **Динамические ссылки (`url`)** | **+2** | В меню (`base.html`) использован тег `{% url 'name' %}`, а не жесткие ссылки `/about/`. Переходы работают. |
| **Работа с контекстом** | **+1** | Данные передаются из `views.py` в шаблон через словарь и выводятся через `{{ var }}`. |

### Штрафы

* **-2 балла:** Копипаста (меню навигации скопировано в оба файла `html`, `base.html` не используется или пуст).
* **-1 балл:** Жесткие ссылки в меню (например `href="http://127.0.0.1:8000/about"`). Это сломается при деплое.
* **-1 балл:** "Битые" ссылки (ошибка 404 при клике в меню).
